我的記帳 PWA
================

功能：
- 收入 / 支出快速記帳
- 自訂日期、分類、備註
- 每月收入、支出、結餘統計
- 支出分類比例
- 每月明細
- CSV 匯出備份
- localStorage 儲存
- PWA 基礎設定，可加入 iPhone 主畫面

iPhone 加到主畫面：
1. 先把此資料夾部署到 HTTPS 網站（例如 GitHub Pages / Netlify / Cloudflare Pages）
2. 用 Safari 打開網址
3. 點分享
4. 選「加入主畫面」
5. 之後會像 App 一樣從桌面直接開啟

注意：
目前資料存在瀏覽器 localStorage。
若清除 Safari 網站資料，紀錄可能消失，所以建議每月匯出 CSV。
